# Ассистент технической поддержки Банка «Первомайский»

Telegram-бот для автоматизации технической поддержки клиентов банка на основе архитектуры **Advanced RAG (Retrieval-Augmented Generation)** с двухэтапным поиском, локальным инференсом моделей и сквозным мониторингом качества.

---

## Архитектура и технологический стек

Вся система спроектирована по микросервисной схеме и разворачивается одной командой через **Docker Compose**:

*   **`tg-bot` - главный оркестратор данных через фреймворк LlamaIndex.
* qdrant - векторная БД.
*   **`vllm`- сервер инференса vLLM для локального запуска квантованной модели **Qwen2.5-7B-Instruct-AWQ** .
*   **Пайплайн поиска:**
    1.  *Retrieve:* Локальное вычисление векторов в контейнере бота с помощью `HuggingFaceEmbedding`.
    2.  *Reranking:* Пост-процессинг кандидатов через нативный `SentenceTransformerRerank` на базе кросс-энкодера `BAAI/bge-reranker-base`.
*   **`langfuse` & `langfuse-db` сервер + база данных PostgreSQL для сквозного логирования.

## Структура проекта

```text
├── .env                  # Секретные ключи и переменные окружения хоста
├── docker-compose.yml    # Манифест оркестрации контейнеров
├── config.py             # Централизованная конфигурация параметров
├── tg_bot.py             # Точка входа и асинхронные хэндлеры бота
├── vector_database.py    # Логика работы с Qdrant, ретрива и реранкинга
├── loader.py             # Скрипт первоначальной нарезки документов (чанкер)
├── main.py               # Скрипт первоначального наполнения Qdrant + запуск бота в консоли
├── requirements.txt      # Список зависимостей для сборки контейнера бота
├── Dockerfile            # Инструкция сборки контейнера Telegram-бота
└── data/                 # Папка с исходными текстовыми документами базы знаний (.txt)
```

## Запуск

### 1. Требования к хосту
*   Установленный Docker Desktop.
*   Минимум **8 ГБ выделенной видеопамяти (VRAM)**.

### 2. Создание папки кэша на диске E: (Windows / WSL)

```bash
mkdir E:\huggingface_cache
```

### 3. Настройка переменных окружения
Создайте в корне проекта файл `.env`:
```env
TELEGRAM_BOT_TOKEN=your_bot_token_here
HF_TOKEN=your_huggingface_token_if_needed

LANGFUSE_PUBLIC_KEY=pk-lf-...
LANGFUSE_SECRET_KEY=sk-lf-...
LANGFUSE_HOST=http://langfuse:3000
```

### 4. Запуск

```bash
docker compose up -d --build
```
### 5. Индексация документов базы знаний
Поместите текстовые файлы с инструкциями вашей техподдержки в папку `data/`. Для того чтобы нарезать их на чанки, вычислить эмбеддинги и загрузить в Qdrant, выполните скрипт `main.py` внутри запущенного контейнера бота:
```bash
docker compose exec tg-bot python main.py
```

# Проект: Corporate_Knowledge_Assistant

## Описание

Этот проект представляет собой реализацию корпоративного ассистента по внутренней базе документов образовательной организации (гимназия).
Для работы с PDF используется библиотек PyMuPDF, для HTML — BeautifulSoup.
Реализован механизм поиска Retriever+Reranker с помощью библиотеки LlamaIndex.
Используется векторная БД Qdrant.
Используется Ollama + локальная модель hf.co/Qwen/Qwen3-4B-GGUF:Q4_K_M


## Описание файлов

*   **main.py** основной файл
*   **loader.py:** загрузка документов + чанкование. Документы находятся в папке data/
*   **vector_database.py:** работа с Qdrant + механизм поиска Retriever+Reranker.
*   **check_services.py** проверка доступности Qdrant + Ollama

## Установка и запуск

Для запуска проекта на вашей локальной машине выполните следующие шаги:

1.  **Клонируйте репозиторий:**
2.  **Установите зависимости:**
    bash pip install -r requirements.txt
3.  **Запустите Qdrant в Docker:**
    docker-compose up -d
4.  **Запустите приложение:**
    python main.py
